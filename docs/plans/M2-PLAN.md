## 단위별 메모

### U1

- ANA-002, ANA-003 완료. 비교 정책(전체 발송 정책, 무작위 타겟팅, 반응 모델) 결정을 PROBLEM.md에 반영.

### U3: U2 점검에서 본 추정량 비교(2026-11-26)

- 학습 세트 44,800명, `visit`, fold seed 42, 부트스트랩 1,000회, outcome model은 처치군별 logistic regression의 OOF. 95% 구간 폭(IPW / Hájek / AIPW): 모두 남성용 0.0130 / 0.0121 / 0.0120, 무작위 타겟팅 0.0063 / 0.0063 / 0.0062, T-learner 상위 50% 발송 0.0119 / 0.0109 / 0.0111, 그 정책과 모두 남성용의 차이 0.0129 / 0.0117 / 0.0117. Hájek과 AIPW는 IPW보다 7\~9% 좁고 둘 사이 차이는 거의 없다.
- Hájek 편향: μ̂를 참 방문 확률로 두고 배정만 다시 뽑은 시뮬레이션(T-learner 상위 50% 정책, 고객 30\~44,800명)에서 세 추정량 모두 편향이 몬테카를로 오차(학습 세트 크기에서 약 0.0001) 안이었다. 편향은 추정량 선택의 제약이 되지 않는다.
- 이 수치는 결과 파일 없이 점검 스크립트로 낸 값이다. U3 EXP-001에서 비교 정책으로 같은 비교를 결과 파일로 다시 낸다.
- 사용자 의견(2026-11-26): AIPW는 outcome model이 따로 필요하므로, U3에서 AIPW가 Hájek보다 뚜렷이 좁지 않으면 Hájek이 낫다. 판정 기준(얼마나 좁아야 뚜렷한가)은 U3 설계 절에 숫자로 적는다.

### U3, U5: 모델링에 가져갈 것(ANA-002, ANA-003)

- 변수: `history_segment`는 빼고 `history`만 쓴다(Spearman 0.97). 구매 상품 세그먼트를 한 변수로 넣는 안과 `mens`, `womens`를 그대로 넣는 안을 1단계에서 함께 본다.
- 모델 점검: 예측 uplift를 ANA-003 세그먼트별로 평균 내어 관측 효과(`artifacts/ANA-003/tables/segment_effects.csv`)와 비교한다. 첫 확인점은 남성 상품만 산 고객의 여성용 효과가 0에 가깝게 나오는지다.
- 판정 규칙의 기대치: 남성용이 거의 모든 세그먼트에서 `visit` 효과가 같거나 커서, 고른 정책과 전체 발송 정책의 `visit` 차이가 작게 나올 수 있다. 이 예상과 근거를 설계 절에 결과보다 먼저 적는다.
- 데이터 경계: 둘 다 산 고객과 Multichannel의 `history` 200 하한, `history` 500 이상은 모두 신규 고객. 모델이 이 경계를 효과처럼 쓰는지 본다.

### U6: 금액 모델

- 퍼널 분해의 가정(늘어난 방문 1회당 구매가 처치 안에서 세그먼트로 다르지 않음)은 반박되지 않았다(`artifacts/ANA-003/tables/funnel_by_product.csv`).
- 신규 고객은 `visit` 효과가 기존 고객과 비슷한데 `spend` 효과가 더 크다. 퍼널 분해가 이 차이를 잡는지 두 부분 모델과 비교할 때 이 세그먼트를 따로 본다.
