# M3 계획: 정책과 인사이트

M3 단계에서 아래 노트를 근거로 계획을 다듬는다. 지금은 앞 단계 분석에서 나온 아이디어를 모아 둔다.

## 분석에서 나온 아이디어

### 이익 최대화형 정책

- `visit`만 보면 남성용이 거의 모든 세그먼트에서 같거나 나아 개인화의 몫이 작다. 이득은 비용을 넣어 효과가 작은 고객을 빼는 판단에서 나올 가능성이 크다. 후보: 남성 상품만 산 고객에게 보내는 여성용 메일(`visit` 효과 0.013), Phone 고객(평소 웹 방문이 적어 방문이 매출을 덜 대신할 수 있음). ANA-003 C1, B1.
- 신규 고객은 `spend` 효과가 기존 고객보다 크다(남성용 1.04 대 0.62). 이익 기준으로 고를 때 신규 고객이 더 뽑히는지 본다. ANA-003 C1.
- 둘 다 산 고객은 전체의 10%인데 남성용 메일로 늘어난 매출의 25%를 차지한다. ANA-003 C2.

### 비교 정책과 uplift 모델의 고객 선택 비교

- 비용 가정을 정할 때 메일마다 1건 비용이 다른지, 발송 수와 무관한 고정비가 있는지 확인한다. 이익 최대화형 정책은 보낼 고객 수를 스스로 정하므로, 반응 모델과 비교할 비용을 그 정책에서 가져온다.

- Rural 고객은 평소 방문율이 높지만 메일 효과는 다른 지역보다 크지 않다. 반응 확률로 고를 때와 효과로 고를 때 선택이 갈라지는 사례로 보인다(THEORY.md Radcliffe 사례). ANA-003 B2, C1.

### 세그먼트 규칙과 Sleeping Dogs

- surrogate tree가 `history` 200 하한(둘 다 산 고객, Multichannel)이나 500 경계(신규 고객)로 나누면, `history`를 맞춘 비교로 다시 확인한 뒤 규칙으로 쓴다. ANA-002 3절, ANA-003 A1.
- 세그먼트 단위에서는 메일이 결과를 줄인 곳이 없다. Sleeping Dogs 점검은 고객별 예측으로 한다. ANA-003 C1.

### 담당자 질문(SPEC.md 6절)과 포트폴리오

- 흐름: "여성용이 매출에서 낫지 않나"는 첫 질문, 구매 고객끼리 비교하는 함정(차이 2.1, 구간 -26.9\~23.1), 구매 상품과 메일의 짝(여성용은 여성 상품만 산 고객에게 남성용과 같은 방문 효과, 남성 상품만 산 고객에게는 매우 작음), 지금 데이터로 답할 수 없는 질문과 필요한 실험 크기(군마다 구매 고객 1,915명). ANA-002 4절, ANA-003 C1, D.
- 후속 실험 제안: 메일 내용(상품 구성, 가격대)을 바꾼 처치, 구매 고객이 아니어도 관측되는 지표 기록. ANA-003 D3.
- 데이터를 의심한 과정: 가족 구매 가설을 확인하다 200 하한을 찾았다. ANA-003 A1.
- 메일은 고액 구매도 늘렸다(200달러 초과 비율 0.0008에서 0.0025). ANA-003 D2.
