## 2026-11-22 대시보드는 백엔드 없는 정적 웹으로 만든다

- 결정:
  - 정적 웹 대시보드를 Vercel에 별도 프로젝트로 배포한다. 기술은 사이트와 같은 Astro + React이고, 사이트의 디자인 토큰을 따른다.
  - 백엔드는 두지 않는다. 고객별 uplift 점수와 처치별 예측은 오프라인에서 미리 계산해 정적 파일로 보낸다. 비용과 타겟팅 비율을 바꾸는 계산은 브라우저 안에서 한다.
  - 실시간 예측 같은 기능이 필요해지면 프론트엔드와 분리한 백엔드를 붙인다. 후보는 HF Space가 먼저이고, 요구사항에 못 미치면 다른 선택지를 찾는다.

- 기각한 대안: Streamlit. 콜드 스타트 때문에 쓰지 않는다.
- 정본: 아직 없음. M4 대시보드에 반영한다.
