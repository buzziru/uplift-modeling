# 용어집

프로젝트 안에서 특정한 뜻으로 쓰는 용어를 모은다. 새 용어는 문서에 처음 쓸 때 여기에 함께 적는다.

| 용어 | 정의 | 처음 쓴 곳 |
| --- | --- | --- |
| 정책 가치 | 정해진 타기팅 정책대로 메일을 보냈다면 얻었을 평균 결과(방문, 매출, 이익). 무작위 실험 데이터에서 IPW로 추정한다. | SPEC.md 5절 |
| 증분 이익 | 정책을 따랐을 때의 이익에서 아무에게도 보내지 않았을 때의 이익을 뺀 값. 증분 매출 × 마진 − 발송 비용으로 계산한다. | SPEC.md 5절 |
| 반응 모델 | 처치 효과가 아니라 메일을 받았을 때의 반응 확률로 대상을 고르는 기준선 모델. | SPEC.md 4절 |
| 세그먼트 규칙 | 추정한 처치 효과를 얕은 의사결정나무(surrogate tree)로 근사해 얻은, 사람이 읽을 수 있는 고객군 정의. | SPEC.md 6절 |
| sleeping dog | 메일을 받으면 반응이 오히려 줄어드는, 처치 효과가 음수인 고객군. | SPEC.md 6절 |
| 기준값 파일 | 채택한 실행의 지표를 고정한 파일. 회귀 테스트가 새 결과를 이 값과 비교한다. | SPEC.md 9절 |
| 승인 지점 | 작업을 멈추고 사용자 승인을 받는 결정. | SPEC.md 11절 |
