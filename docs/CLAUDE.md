# docs 규약

`docs/`의 문서 종류와 각 문서에 담는 것은 SPEC.md 문서 체계 절이다.

- 단계 계획은 `docs/plans/M<번호>-PLAN.md`로 둔다. 그 단계의 작업에서 참고만 하고, 다른 파일은 인용하지 않는다. 계획에서 나온 것이 결정이 되면 정본과 기록 문서에 남긴다.
- `docs/THEORY.md`와 `docs/glossary.md`는 다른 파일이 가리킬 수 있다.
- 기록 문서의 바뀐 이력 줄이 문서 전체 줄의 20%를 넘으면, 그 문서의 바뀐 이력을 `docs/history/<문서 이름>.md`로 옮기고 각 항목에는 옮긴 곳을 한 줄로 남긴다. `.claude/harness/check_docs.py`가 비율을 재어 넘으면 알린다.
- 용어집에 올리기 전에 정착한 용어가 있는지 찾는다.

## NARRATIVE.md

각 마일스톤을 마칠 때 그 단계의 성과 자료를 더한다. 자료는 세 가지다.

- 주장 문장: 무엇을 판단했고 결과가 어땠는지를 한 문장으로 쓴다.
- 근거 수치: 조건(데이터 범위, 행 수, 기준선)과 결과 파일 경로를 함께 적는다.
- 그림 값: 기준선과 최종값, 차이의 95% 구간, 세그먼트별 효과처럼 사이트가 그릴 값을 적는다.

사이트 항목의 형식(필드, 그림 데이터 형식)은 사이트 저장소의 콘텐츠 스키마를 따른다.
