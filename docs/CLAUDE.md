# docs 규약

`docs/`에는 성격이 다른 세 종류가 있다.

- 기록 문서(`docs/glossary.md`): 결정과 근거의 기록. 형식과 인용 규칙은 SPEC.md 10절이다.
- 이론과 용어: `docs/THEORY.md`, `docs/glossary.md`. 다른 파일이 절 위치로 가리킬 수 있다.
- 단계 계획(`docs/glossary.md`): `docs/plans/M<번호>-PLAN.md`. 마일스톤의 작업 분해, 단위별 메모, 앞 단계 분석에서 나온 아이디어를 모은다. 그 단계의 작업에서 참고만 하고, 다른 파일은 인용하지 않는다. 계획에서 정한 것은 결정이 되면 정본과 기록 문서에 남기고, 계획에는 결정을 다시 적지 않는다.

- 기록 문서의 바뀐 이력 줄이 문서 전체 줄의 20%를 넘으면, 그 문서의 바뀐 이력을 `docs/history/<문서 이름>.md`로 옮기고 각 항목에는 옮긴 곳을 한 줄로 남긴다. `.claude/harness/check_docs.py`가 비율을 재어 넘으면 알린다.
- 용어집에 올리기 전에 정착한 용어가 있는지 찾는다.
