# docs 규약

기록 문서의 형식과 인용 규칙은 SPEC.md 10절이다.

- 바뀐 이력 줄이 문서 전체 줄의 20%를 넘으면, 그 문서의 바뀐 이력을 `docs/history/<문서 이름>.md`로 옮기고 각 항목에는 옮긴 곳을 한 줄로 남긴다. `.claude/harness/check_docs.py`가 비율을 재어 넘으면 알린다.
- 용어집에 올리기 전에 정착한 용어가 있는지 찾는다. 한국어 표기가 정착했으면 그것(퍼널)을, 아니면 원어(base learner)를 쓴다. 정착한 용어가 없을 때만 내부 용어를 만든다. 내부 용어는 영어 낱말을 낱말 단위로 옮기지 않는다. 다른 분야에서 다른 뜻으로 자리 잡은 말(대리 결과)도 쓰지 않는다.
