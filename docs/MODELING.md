# MODELING.md: 모델링

담는 범위: 모델 후보, 선택 이유, 하이퍼파라미터 탐색.

기록 문서다(SPEC.md 10절). 결정한 날짜순으로 항목을 둔다.


## 2026-11-23 방법론을 먼저 같은 부품 모델로 비교해 정하고, 그다음 부품 모델 알고리즘을 비교한다

- 결정:
  - 방법론 후보는 S-learner, T-learner, X-learner, DR-learner, class transformation, transformed outcome, uplift random forest(`causalml`)다. 각 방법의 정의는 `docs/THEORY.md` "대표 방법" 절을 출발점으로 삼는다. DR-learner와 uplift random forest는 아직 그 절에 없어 M2 모델링 전에 더한다.
  - class transformation과 transformed outcome은 이진 처치를 전제한다. 어느 이진 정의로 비교할지는 SPEC.md 14절 미결 사항이고 M2 승인 지점에서 닫는다.
  - 1단계: 부품 모델을 LightGBM으로 고정하고 방법론끼리 비교해 방법론을 정한다. uplift random forest는 자체 트리를 쓰므로 부품 모델이 없다.
  - 2단계: 정한 방법론 안에서 부품 모델 알고리즘을 비교한다.
  - 1단계의 방법론 결정과 2단계의 최종 선택은 모두 SPEC.md 11절 "모델 선택" 승인 지점이다. 비교 결과를 붙여 승인을 받는다. 선택 기준은 `docs/EVALUATION.md` "모델은 학습 세트 OOF 예측의 visit 정책 가치로 고르고 seed 세 개의 변동으로 흔들림을 본다" 절이다.
  - 비교와 결합에는 OOF 예측을 쓴다. OOF 예측은 학습 세트 안 5-fold CV에서 나오고, 시험 세트는 쓰지 않는다.
  - 결합 후보는 두 가지다. 같은 방법론에서 서로 다른 알고리즘을 결합하거나, 서로 다른 방법론을 결합한다. 결합 가중치는 OOF 예측의 Qini나 AUUC로 정한다. Qini·AUUC는 모델 선택 기준으로 쓰지 않고, 순위 품질 보고는 SPEC.md 5절을 따른다. 결합 모델도 단일 모델과 같은 후보로 보고 같은 기준으로 고른다.
- 근거: 사용자 지시(2026-11-23). 아직 결과 수치는 없다.
- 기각한 대안: 방법론과 부품 모델 알고리즘의 모든 조합을 한 번에 비교하는 안. 사용자가 순서를 나눠 정했고, 조합 수가 방법론 수와 알고리즘 수의 곱으로 늘어 CV 실행이 그만큼 많아진다.
- 정본: 아직 없음. M2 실험의 설계 절과 설정에 반영한다.
- 승인: 2026-11-23

## 2026-11-24 고객별 증분 금액은 깔때기 분해와 두 부분 모델로 따로 만들어 비교하고, 모델 선택에는 쓰지 않는다

- 결정:
  - 모델 선택은 `docs/EVALUATION.md` "모델은 학습 세트 OOF 예측의 visit 정책 가치로 고르고 seed 세 개의 변동으로 흔들림을 본다" 절 그대로다. 금액 모델은 고르는 기준에 쓰지 않는다.
  - 고객별 증분 금액을 두 모델로 만든다.
    - 깔때기 분해(`docs/glossary.md`).
    - 두 부분 모델(hurdle model): 구매 확률 uplift x 구매 시 금액.
  - 두 모델의 증분 금액은 M3 이익 최대화형 정책(SPEC.md 6절)에서 고객과 메일을 고르는 데 쓴다. 그렇게 고른 정책의 이익은 모델 예측값이 아니라 실제 `spend`의 IPW 정책 가치로 재고, `docs/PROBLEM.md` 성공 절의 비즈니스 판단(`docs/glossary.md`)으로 두 금액 모델의 정책을 함께 보고한다.
  - 두 모델의 차이가 `spend` 잡음 안에 들면 깔때기 분해를 기본으로 둔다. 잡음 안에 드는지를 가를 숫자는 M2 실험의 판정 규칙(`experiments/TEMPLATE.md` 설계 절)에 결과보다 먼저 적는다.
  - 깔때기 분해는 늘어난 방문 1회의 가치가 처치마다만 다르고 고객 특성으로는 크게 다르지 않다고 가정한다. 이 가정은 M2에서 확인한다. 방법 후보는 세그먼트별 늘어난 방문 1회당 구매를 구간과 함께 비교하는 것과, OOF `spend` IPW 정책 가치로 두 금액 모델을 비교하는 것이다.
- 근거: 사용자 지시(2026-11-24). 메일로 늘어난 방문 1회당 구매는 남성용 0.0889, 여성용 0.0688, 대조군의 방문 1회당 구매는 0.0539라 처치마다 다르다(`artifacts/ANA-001/tables/funnel.csv`). 깔때기 분해는 신호가 큰 `visit` 모델을 쓰는 대신 위 가정에 기댄다. 두 부분 모델은 그 가정이 없지만, 구매 확률 uplift를 처치별 구매 고객 86\~187명(`artifacts/data/profile.json`의 `splits`)으로 배워 `spend` uplift 학습(`docs/PROBLEM.md` 첫 절의 기각한 대안)과 같은 이유로 흔들린다. 둘은 서로 다른 약점을 지니므로 한쪽을 미리 버리지 않고 비교하고, 차이가 잡음 안에 들면 신호가 큰 깔때기 분해를 기본으로 둔다.
- 기각한 대안: `spend` uplift를 따로 학습하는 안과 방문 1회 가치를 하나로 가정하는 안. 기각 이유는 `docs/PROBLEM.md` "고객별 순위와 모델 선택은 visit으로 하고, 정책의 이익은 실제 spend의 IPW 추정으로 잰다" 절.
- 정본: 아직 없음. M2\~M3 금액 모델 코드에 반영한다.
- 승인: 2026-11-24
