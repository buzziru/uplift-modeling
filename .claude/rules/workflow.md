# 작업 규칙

- 작은 수정과 결정은 작업 트리나 진행 중인 브랜치에 모으고, 브랜치를 새로 만들거나 PR을 열기 전에 묶을 범위를 사용자와 정한다. 하네스 파일 수정은 작업 변경과 다른 브랜치에 모은다. 하네스 PR은 이미 본 실수가 되풀이되지 않게 하는 변경이면 범위를 정한 뒤 쌓아 두지 않고 바로 열고, 그 밖의 변경은 하네스 브랜치에 쌓았다가 작업을 막을 때나 마일스톤을 닫을 때 연다. `experiments/`의 실험 폴더 하나는 묻지 않고 PR 하나로 한다.
- 실수가 되풀이되면 먼저 그 실수가 생기는 자리를 구조로 없앤다(같은 사실을 한 곳에만 두거나 코드·표에서 만들기, 실행 단계를 나눠 다시 할 범위 줄이기). 구조로 없앨 수 없을 때만 탐지 검사를 더한다. 탐지 검사는 같은 꼴의 오류가 서로 다른 작업 두 곳에서 나왔고, 문자열만으로 판정되며, 지금 저장소에서 오탐이 없을 때 오류로 더한다. 알림은 새로 만들지 않고, 같은 오탐을 되풀이하는 알림은 고치거나 지운다. 의미, 과장, 설계와의 대조는 검사로 옮기지 않고 평가와 검토에 둔다.
- 정본의 내용을 하네스 파일에 옮겨 적지 않는다. 가리켜야 하면 파일 이름만 쓴다.
